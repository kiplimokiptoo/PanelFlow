# PanelFlow Admin

Simple React e-commerce administrator portal built for the summative lab.

## Features

- Landing dashboard
- Product list with live search
- Add product form
- Product detail page with price/product updates
- Delete products
- React Router client-side routes
- Custom `useProducts` hook
- JSON Server simulated backend in `db.json`
- Jest and React Testing Library tests

## Run Locally

Install dependencies:

```bash
npm install
```

Start the backend:

```bash
npm run server
```

Start the React app in another terminal:

```bash
npm run dev
```

Run tests:

```bash
npm test -- --runInBand
```
